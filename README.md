# Imider Village

Website for the Amazigh village of Imider: culture, tourism and heritage.

## Features

- Village, culture and environment sections
- Tourism and services
- News and contact

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router
- Leaflet

## Getting Started

```bash
git clone https://github.com/ghostland-dev/imider-oasis-gateway.git
cd imider-oasis-gateway
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
